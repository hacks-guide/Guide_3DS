1. Exécuter le script MSET9 :
   - **Windows** : Double-cliquez sur `MSET9-Windows` (ou `MSET9-Windows.bat`)
   - **macOS** : Double-cliquez sur `MSET9-macOS.command` et entrez votre mot de passe si vous y êtes invité
   - **Linux** : Montez votre carte SD en la sélectionnant dans votre gestionnaire de fichiers, puis double-cliquez sur `MSET9` (ou `MSET9-Linux.desktop`) depuis votre Bureau
     - `MSET9-Linux.desktop` ne fonctionnera pas sous Linux depuis la carte SD. Il doit être sur votre Bureau
     - Alternativement, ouvrez une fenêtre du terminal, `cd` vers la racine de votre carte SD puis saisissez `python3 mset9.py` et appuyez sur Entrée
