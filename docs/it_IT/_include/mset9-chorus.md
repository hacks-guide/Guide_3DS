1. Esegui lo script di MSET9:
   - **Windows**: Clicca due volte `MSET9-Windows` (o `MSET9-Windows.bat`)
   - **macOS**: Fai doppio-click su `MSET9-macOS.command` e inserisci la tua password se richiesto
   - **Linux**: Monta la scheda SD selezionandola dal gestore dei file, poi clicca due volte `MSET9` (o `MSET9-Linux.desktop`) dal tuo Desktop
     - `MSET9-Linux.desktop` non può essere eseguito dalla scheda SD. Deve essere sul tuo Desktop
     - Alternativamente, apri una finestra del terminale, `cd` nella directory principale della tua scheda SD, quindi digita `python3 mset9.py` e premi Invio
