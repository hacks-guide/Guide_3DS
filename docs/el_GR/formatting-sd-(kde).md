# Διαμόρφωση της SD (Διαχειριστής κατατμήσεων του KDE)

## Απαραίτητη ανάγνωση

::: info

Εάν χρησιμοποιείτε μια συσκευή SteamOS (π.χ. Steam Deck ή Steam Machine), θα πρέπει να εισέλθετε στη [λειτουργία επιφάνειας εργασίας (Desktop Mode)](https://help.steampowered.com/en/faqs/view/671A-4453-E8D2-323C) για να ακολουθήσετε τις οδηγίες σε αυτήν τη σελίδα.

:::

::: warning

Αυτή η σελίδα αφορά μόνο τους χρήστες Linux που έχουν πρόσβαση στον Διαχειριστή κατατμήσεων του KDE. Εάν δεν χρησιμοποιείτε Linux, δείτε τις σελίδες [Διαμόρφωση της SD (Windows)](formatting-sd-(windows)) ή [Διαμόρφωση της SD (Mac)](formatting-sd-(mac)). Εάν χρησιμοποιείτε Linux αλλά δεν έχετε πρόσβαση στον Διαχειριστή κατατμήσεων του KDE, ακολουθήστε τις οδηγίες στη σελίδα [Διαμόρφωση της SD (Linux)](formatting-sd-(linux)).

:::

## Οδηγίες

1. Εισαγάγετε την κάρτα SD στον υπολογιστή σας

2. Εάν η κάρτα SD περιέχει τυχόν αρχεία και φακέλους, αντιγράψτε τα πάντα σε έναν φάκελο στον υπολογιστή σας

3. Αφαιρέστε την κάρτα SD από τον υπολογιστή σας

4. Ανοίξτε τον Διαχειριστή κατατμήσεων του KDE, πληκτρολογώντας τον κωδικό πρόσβασής σας, εφόσον σας ζητηθεί

5. Εισαγάγετε την κάρτα SD σας και κάντε κλικ στο `Ανανέωση συσκευών`
   - Η νέα συσκευή που εμφανίζεται στην αριστερή πλευρά είναι η κάρτα SD σας

6. Επιλέξτε την κάρτα SD σας και κάντε κλικ στο κουμπί `Νέος πίνακας κατατμήσεων` στο πάνω μέρος του παραθύρου
   ::: danger

   Βεβαιωθείτε ότι έχει επιλέξει τη σωστή συσκευή, διαφορετικά ενδέχεται να διαγράψετε ακούσια τον λανθασμένο δίσκο!

   :::

7. Όταν σας ζητηθεί, επιλέξτε `MS-Dos`. **ΜΗΝ** χρησιμοποιήσετε τον τύπο GPT.

   ::: info

   ![](/images/screenshots/kde/mbr.png)

   :::

8. Κάντε δεξί κλικ στον `αδέσμευτο` χώρο στη δεξιά πλευρά και επιλέξτε `Νέα`

9. Κατά την επιλογή του συστήματος αρχείων, επιλέξτε `FAT32` από το αναπτυσσόμενο μενού. Το παράθυρο θα πρέπει να μοιάζει κάπως έτσι:

   ::: info

   ![](/images/screenshots/kde/new-partition.png)

   :::

10. Κάντε κλικ στο `Εντάξει`, επιλέξτε `Εφαρμογή` και έπειτα, `Εφαρμογή ενεργειών σε αναμονή`

11. Αφαιρέστε και τοποθετήστε ξανά την κάρτα SD σας

12. Εάν η κάρτα SD περιείχε οποιαδήποτε αρχεία και φακέλους πριν από τη διαμόρφωση, αντιγράψτε τα πάντα από τον υπολογιστή στην κάρτα SD σας
